# Merch It — מודול סושיאל

סוכן ניסוח ולוח טיוטות לפלטפורמה אחת (לינקדאין של מאמא בוי). בלי תלויות חיצוניות.

## הפעלה
דורש Node 22.13 ומעלה.

    npm start          # http://localhost:3000
    npm test

הנתונים נשמרים ב-`data/social.sqlite` (משתנה `SOCIAL_DB`), ולכן שורדים כיבוי והפעלה מחדש.

## ספק AI
- עם `ANTHROPIC_API_KEY` בסביבה: הסוכן קורא ל-API ושומר את התוצאה כגרסה. המודל ב-`SOCIAL_MODEL`.
- בלי מפתח: העבודה נשמרת כ-`waiting_for_input` עם הפרומפט המלא, והיוצר מדביק נוסח ידנית. שום ריצה לא מדומה.

## זרימה
טיוטה → אושרה → יוצאה → (תוזמנה) → פורסמה.
"פורסמה" דורש קישור לפוסט או רישום ידני. אין פרסום אוטומטי. עריכה אחרי אישור מחזירה לטיוטה, וגרסאות ישנות נשמרות.
