## שילוב
קרב בלולאה → נשיקה → פתיחה פעם אחת → הקפאת פריים אחרון עד הנשיקה הבאה → סגירה פעם אחת → קרב.
הקטע הישן והחדש שונים בתנוחה. אין לטעון שהמעבר מושלם: מומלץ מעבר קצר של 80–120ms בשני נגנים טעונים מראש, ולבדוק בתצוגה הקטנה של הדלת. גם גבול לולאת הקרב הוא חיתוך עריכה ולא לולאה מדויקת. אפשר להסוות בחיווי אדום של פגיעת לייזר, בלי הבזק חזק או מסך שחור.
למנוע טריגר כפול בזמן פתיחה/סגירה. הזכוכית והדלת כבר בסרטון; לא להניע מעליו דלת נפרדת. muted ו־playsinline.
